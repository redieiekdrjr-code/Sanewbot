# Sanew Stars Android

This Android project packages the browser game as a standalone APK. The game files are bundled locally in `app/app/src/main/assets/www`, so no server or internet connection is needed to play.

GitHub Actions builds a debug-signed APK. Download it from the Actions run artifact named `Sanew-Stars-APK`. Debug APKs are installable on Android but are intended for testing rather than Play Store publication.
