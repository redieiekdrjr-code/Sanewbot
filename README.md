# Sanewbot

Telegram-бот на Python и aiogram 3.

## Возможности
- `/start` — приветствие
- `/help` — список команд
- `/joke` — случайная шутка
- Простые ответы на сообщения

## Настройка
1. Создай бота через BotFather и получи новый токен.
2. В настройках окружения хостинга добавь переменную `BOT_TOKEN` со значением токена.
3. Запусти команду: `uvicorn main:app --host 0.0.0.0 --port $PORT`.

Токен нельзя записывать в файлы репозитория или публиковать в GitHub.

## Render
В репозитории есть `render.yaml` для создания бесплатного Web Service. На бесплатном тарифе сервис может засыпать после периода без запросов, поэтому бот может отвечать с задержкой после пробуждения.
